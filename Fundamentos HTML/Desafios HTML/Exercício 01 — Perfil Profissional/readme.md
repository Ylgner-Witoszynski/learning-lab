# 🟢 Exercício 01 — Perfil Profissional 

## 🎯 Objetivo

Criar uma página HTML apresentando o **perfil profissional de um desenvolvedor fictício**, colocando em prática os fundamentos de HTML5 estudados até agora.

Neste exercício, o foco é praticar:

* Estrutura básica do HTML
* Títulos e subtítulos
* Parágrafos
* `<strong>` e `<em>`
* Imagens
* Listas
* Links
* Comentários
* `div` e `span`

---

## 📋 Enunciado

Imagine que você foi contratado para criar uma página simples de apresentação profissional de um desenvolvedor.

Crie um arquivo chamado:

```text
perfil.html
```

A página deverá apresentar as informações de um **desenvolvedor fictício**.

Você pode inventar o nome, experiência, tecnologias, projetos e demais informações.

---

## 🧱 Requisitos da página

### 1. Informações principais

A página deverá possuir:

* Um **título principal (`h1`)** com o nome do desenvolvedor
* Um subtítulo apresentando sua área de atuação
* Um pequeno texto de apresentação utilizando parágrafos (`p`)

---

### 2. Destaques no texto

Utilize:

* `<strong>` para destacar pelo menos **2 informações importantes**
* `<em>` para dar ênfase em pelo menos **2 trechos**

Pense em informações que realmente façam sentido serem destacadas.

---

### 3. Foto de perfil

Adicione uma imagem representando o desenvolvedor.

A imagem deverá:

* utilizar a tag `<img>`
* possuir o atributo `src`
* possuir o atributo `alt`

O texto do `alt` deve descrever adequadamente a imagem.

---

### 4. Tecnologias

Crie uma seção chamada **Tecnologias**.

Apresente pelo menos **5 tecnologias** que o desenvolvedor conhece.

Utilize uma lista não ordenada:

```html
<ul>
    <li>...</li>
</ul>
```

---

### 5. Experiência ou trajetória

Crie uma seção chamada **Experiência** ou **Minha trajetória**.

Apresente pelo menos **3 experiências ou etapas** da carreira.

Aqui você deverá utilizar uma **lista ordenada (`ol`)**, pois existe uma sequência entre os itens.

---

### 6. Links

Adicione uma seção chamada **Links profissionais**.

Inclua pelo menos:

* GitHub
* LinkedIn
* Um terceiro site relacionado à tecnologia

Utilize a tag `<a>`.

Os links devem realmente funcionar.

---

### 7. Comentários no código

Adicione comentários HTML identificando as principais partes da página.

Por exemplo:

```html
<!-- Informações principais -->
```

Utilize comentários para separar logicamente as diferentes partes do documento.

---

### 8. Organização com `div` e `span`

Utilize pelo menos:

* **2 elementos `<div>`** para organizar partes diferentes da página
* **1 elemento `<span>`** para destacar ou agrupar um pequeno trecho de conteúdo

Não utilize `div` ou `span` simplesmente para atingir a quantidade mínima.

Pense em **onde eles fazem sentido na estrutura**.

---

## ⭐ Desafio extra

Tente deixar a estrutura da página organizada de maneira que outra pessoa consiga abrir seu código e entender facilmente onde começa e termina cada parte.

**Não utilize CSS ou JavaScript neste exercício.**

O objetivo é trabalhar **somente o HTML**.

## 💡 Regra importante

**Tente resolver sozinho antes de pesquisar a solução pronta.**

Se esquecer alguma tag ou atributo, pesquise **o conceito específico** em vez de procurar um código completo para copiar.

O objetivo não é terminar rapidamente.

O objetivo é conseguir olhar para o enunciado e pensar:

> "Eu sei quais elementos HTML preciso usar para construir isso."
