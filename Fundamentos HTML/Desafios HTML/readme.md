# 🧩 Desafios de HTML5

Repositório criado para praticar e consolidar os conhecimentos adquiridos durante meus estudos de **HTML5** por meio de exercícios progressivos.

A proposta é começar pelos fundamentos e aumentar gradualmente a complexidade dos desafios, incluindo exercícios que incentivam a **pesquisa e a resolução independente de problemas**.

---

## 🎯 Objetivos

* Consolidar os fundamentos do HTML5
* Praticar a criação de páginas HTML
* Desenvolver uma boa estrutura de documentos
* Utilizar elementos e atributos corretamente
* Trabalhar com listas, tabelas, formulários e links
* Desenvolver páginas com HTML semântico
* Aplicar conceitos básicos de acessibilidade
* Aprender a pesquisar e utilizar novos recursos da linguagem
* Desenvolver autonomia na resolução de problemas

---

## 📚 Conteúdos praticados

Ao longo dos desafios serão trabalhados conceitos como:

* Estrutura básica do HTML5
* `head` e `body`
* Títulos e parágrafos
* Formatação de texto
* Links
* Imagens
* Listas ordenadas e não ordenadas
* Tabelas
* Formulários
* Tipos de `input`
* `select` e `textarea`
* Elementos semânticos
* Acessibilidade
* WAI-ARIA
* Recursos multimídia
* Boas práticas de HTML

## 🔎 Aprendizado através de pesquisa

Alguns desafios possuem requisitos que ainda não foram abordados diretamente durante os estudos.

Nesses casos, a proposta é **pesquisar, testar e compreender** o novo conceito antes de utilizá-lo.

> O objetivo não é apenas conseguir fazer funcionar, mas entender **o que foi utilizado, como funciona e por que aquela solução foi escolhida**.
