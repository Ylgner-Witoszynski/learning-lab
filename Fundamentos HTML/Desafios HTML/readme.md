# 🟢 NÍVEL BÁSICO

## 🟢 Exercício 01 — Perfil Profissional

Crie uma página HTML apresentando um **perfil profissional fictício de desenvolvedor**.

### Requisitos

- Título principal;
- Subtítulos;
- Alguns parágrafos;
- Trechos utilizando `<strong>` e `<em>`;
- Uma imagem de perfil;
- Uma lista de tecnologias;
- Links para GitHub, LinkedIn e um site;
- Comentários no código identificando as principais partes da página.

### Objetivo

Revisar:

- Estrutura básica do HTML;
- Títulos;
- Parágrafos;
- Formatação de texto;
- Imagens;
- Listas;
- Links;
- Comentários.

### ⭐ Desafio extra

Organize o conteúdo utilizando `<div>` e `<span>` onde fizer sentido.

---

## 🟢 Exercício 02 — Minha Jornada

Crie uma página contando a trajetória de uma pessoa desde o início dos estudos até conseguir seu primeiro emprego na área de tecnologia.

### Requisitos

A página deverá possuir:

- `<h1>`, `<h2>` e `<h3>` organizados hierarquicamente;
- Vários parágrafos;
- Uma lista ordenada representando a evolução da carreira;
- Uma lista não ordenada com habilidades;
- Links internos para diferentes partes da página;
- Um link externo para um site relacionado à tecnologia;
- Uma imagem relacionada ao conteúdo.

### 🔎 Pesquisa obrigatória

Descubra como fazer um link que abra uma página em **nova aba** e aplique isso em pelo menos um link externo.

- Rodapé;

## 🟡 Exercício 06 — Página de Empresa

Crie um pequeno site de uma empresa fictícia de tecnologia com **3 páginas**:

```text
/
├── index.html
├── servicos.html
└── contato.html
````

### Página inicial

Deverá conter:

* Apresentação da empresa;
* Imagem;
* Lista de serviços;
* Links para as outras páginas.

### Página de serviços

Deverá apresentar os serviços oferecidos pela empresa.

### Página de contato

Deverá possuir:

* Informações de contato;
* Links de e-mail;
* Formulário de contato.

### Regras

* Utilize URLs relativas para navegar entre as páginas;
* Utilize pelo menos um link externo;
* Utilize pelo menos um link para uma seção interna;
* Mantenha uma estrutura HTML organizada.

### ⭐ Desafio

Faça com que todas as páginas tenham uma navegação consistente.

# 🟠 NÍVEL INTERMEDIÁRIO / AVANÇADO

## 🟠 Exercício 07 — Reestruturando um HTML

Você recebeu uma página HTML que funciona, mas foi construída de maneira desorganizada.

Sua missão será criar uma versão melhor estruturada.

A página deverá representar um:

> **Portal de notícias sobre tecnologia**

### Requisitos

A página deverá possuir:

* Cabeçalho;
* Menu de navegação;
* Conteúdo principal;
* Pelo menos 3 notícias;
* Conteúdo complementar;
* Informações de contato;
* Rodapé.

### Regra principal

Evite utilizar `<div>` para absolutamente tudo.

Utilize elementos semânticos como:

* `<header>`;
* `<nav>`;
* `<main>`;
* `<section>`;
* `<article>`;
* `<aside>`;
* `<footer>`;
* `<address>`.

### 🔎 Pesquisa obrigatória

Pesquise a diferença entre `<section>` e `<article>`.

Depois, escreva um comentário no código explicando:

* Por que determinado conteúdo foi colocado em `<section>`;
* Por que determinado conteúdo foi colocado em `<article>`.

## 🟠 Exercício 08 — Formulário Acessível

Crie uma página contendo um formulário de:

> **Contato / Suporte Técnico**

O formulário deverá ser pensado considerando um usuário que utiliza leitor de tela.

### Requisitos

O formulário deverá conter:

* Nome;
* E-mail;
* Assunto;
* Tipo de problema;
* Descrição do problema;
* Prioridade;
* Checkbox de confirmação;
* Botão de envio.

### Além disso

* Utilize `<label>` corretamente;
* Utilize `required` quando necessário;
* Utilize elementos semânticos;
* Utilize atributos ARIA somente quando realmente fizer sentido.

### Conceitos estudados

Você poderá trabalhar com:

* `aria-label`;
* `aria-required`;
* `role`;
* `aria-live`;
* `aria-labelledby`;
* `aria-describedby`.

### 🔎 Pesquisa obrigatória

Pesquise por que:

> **HTML semântico e `<label>` corretamente associado devem ser priorizados antes do uso de ARIA.**

Não coloque atributos ARIA aleatoriamente.

Para cada atributo utilizado, procure entender qual problema ele resolve.

# 🟣 PROJETO FINAL

## 🟣 Exercício 10 — Portal de Tecnologia

Agora pense como um **desenvolvedor Front-end recebendo uma pequena demanda de um cliente**.

Crie um site completo para uma empresa fictícia chamada:

> **DevTech Solutions**

### Estrutura mínima

```text
devtech/
│
├── index.html
├── sobre.html
├── servicos.html
├── cursos.html
├── contato.html
│
└── imagens/
```

---

## 🏠 Página Inicial

Deverá apresentar:

* Nome da empresa;
* Apresentação;
* Imagem;
* Principais serviços;
* Links para as outras páginas;
* Navegação interna.

---

## 👥 Página Sobre

Apresente:

* História;
* Missão;
* Visão;
* Valores;
* Equipe.

* Título;

Apresente pelo menos **5 cursos** em uma tabela contendo:

* `<thead>`;
